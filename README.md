Software to maintain the Engineering Heritage Australia wiki at https://heritage.engineersaustralia.org.au/

Items

sitemap.py - creates site map wiki text to insert into the sitemap page on the wiki
summaries.py - creates summaries of new wiki pages (note - needs to be copied to the PyWikibot core folder along with its config file)
check_links.py - checks external links on entire wiki
crosslink.py - inserts intra-wiki links (not yet fully released, no config file available)

coonfig files will need to be edited with apprpriate file paths
